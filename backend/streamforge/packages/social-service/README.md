# Social Service

The social-service manages creator relationships, discovery, engagement, and audience metadata for StreamForge Live.

## Responsibilities

- Creator profiles
- Follow system
- Comments and reactions
- Discovery and trending
- Watch history
- Moderation helpers

## Structure

- `src/app.ts` — Fastify application setup
- `src/server.ts` — Server bootstrap
- `src/routes/` — HTTP route registration
- `src/modules/` — Domain modules
- `src/services/` — Core business services
- `src/repositories/` — Data access stubs
- `src/prisma/` — Prisma schema and migrations
